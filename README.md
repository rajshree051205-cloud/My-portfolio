# 🌐 Rajshree Kavia — Creative UI Developer Portfolio

A modern, interactive and responsive **3D animated portfolio website** created to showcase my skills, experience, projects and journey as a Computer Science student and developer.

The portfolio focuses on **creative UI design, smooth animations and immersive visual experiences** while keeping the interface responsive and user-friendly.

* 🎨 Creative and modern UI design
* 🌌 Animated background canvas
* 🖱️ Custom cursor and cursor trail
* ⚡ Smooth scroll and reveal animations
* 📱 Responsive layout
* 🧩 Interactive navigation
* 💻 Skills showcase
* 💼 Experience section
* 🚀 Projects showcase
* 📩 Contact section

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/rajshree051205-cloud/My-portfolio.git
```

Navigate into the project:

```bash
cd My-portfolio
```

Open the project in VS Code:

```bash
code .
```

Since this portfolio is built using HTML, CSS and JavaScript, it can be run directly by opening the HTML file in a browser or using a local development server.
